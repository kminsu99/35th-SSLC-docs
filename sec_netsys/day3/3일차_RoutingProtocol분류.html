Routing Protocol의 분류

Distance Vector / Link-state

Distance Vector (loop방지 기술6개) : basic : RIP, 하지만 그래도 루프발생함

Advanced Distance Vector : BGP의 기본 알고리즘(=Distance Vecotr) + 자기만의 Loop방지책 추가

Link-State : OSPF(가장많이 사용되는 Routing Protocol) : 안정적 절대 loop발생 x → 중대형망 사용가능 → 큰 메모리, 경로계산cpu필요 → 리소스가 많이 요구된다.

가상화, 클라우드에서 Routing Protocol → BGP가 기본
