1-1.네트워크 정의, 구현 목적

정의 : 통신 매체를 통해 연결된 노드들의 집합
노드 : 주소를 가진 시스템, 엔티티

목적
초기 : Data 공유
발전 : Service 제공

1-3.네트워크 분류

네트워크 범위

  • Personal Area Network(PAN)
  • Local Area Network(LAN)

    과거:
    물리적인 거리(100m)의 한계를 가지고 구축되는 Network
    100m ← 그 당시 통신매체 (UTP케이블)

    현재:
    거리의 한계가 극복됨, 거리로 구별은 애매해짐
    개인(Home LAN)이나 기업(Enterprise LAN)이 소유한 네트워크 < 의미 변함

  • Wide Area Network (WAN)

    광대역 망

SP(Service Provider) - 전국망 미리 설치하고 대여

LAN 기술별 분류

  • Ethernet (~=LAN) : UTP씀
  • TokenRing : UTP못쓰고 STP(더 비쌈, 노이즈 저항 좋음)망 - (은행, 군사, 공항)
  • FDDI : TokenRing 2중

데이터 전송 방식에 따른 분류

  • 주소 - source : unicast addr
    -dest : [uni / multi / broad] cast addr
    -[uni/ multi / broad] cast data (목적지에 따라 data명칭)
  • Unicast

    Unicast addr : 유니크한 주소
    1:1
    네트워크부하 ↑ / 시스템 부하 ↓

  • Broadcast

    Broadcast addr : ALL 모두다사용 주소
    1:多
    네트워크부하 ↓ / 시스템 부하 ↑

  • Multicast

    Multicast addr : Group주소 (여럿이서 쓰는 주소)
    1:ALL
    네트워크부하 ↓ / 시스템 부하 ↓

NIC, 랜카드

[ 전기 신호 ↔ 데이터 ] 변환, 송수신
MAC Address 이용 수신여부 판별
케이블 흐름 제어 (Flow Ctrl)
