3장. 스위칭 기술

3-1. L2 스위치 기본 기능

L2 기능 : 논리적 연결 → 주소 제공(MAC)
L2 장비의 기능 : L2 Switching : L2 정보를 기반으로 Data의 전송 결정

MAC주소 → MAC addr Table

L1의 문제 해결 위해 Bridge 사용 (Collision)
이제는 사용안하고 Switch만 사용

A, B가 동시에 데이터 전송하려한다.
CSMA/CD에서 CS로 먼저 데이터 수신여부확인하고 전송시작

Switch는 L2장치

Signal → Bits → [Data | Src | Dest] (변환 두번)


DATA를 버퍼에 저장
Switch가 받은데이터 Src주소 기반(Unicast기반)
이 기록을 보고 MAC Table작성 (RAM 휘발성 메모리)

F0/1에서 A가 들어왔으니 MAC Table에 “A - F0/1”기록

Switch도 Hub처럼 flooding을 함.
목적지에 대한 정보가 MAC Table에 없을때 모든 경로에 보내봄

Switch는 port별 Collision Domain이 나뉘어진다.

port별 전용 B/W

Dest addr = [ uni / multi / broad ] cast Data
Multicast Addr, Broadcast Addr 이 MAC Table에 기록? → X
이 데이터를 받은 포트를 제외한 모든 포트로 보냄 (flooding)
